وثيقة الربط التقني الموحد للبنوك والمحافظ (Biller API v1)

منصة وزيرك السحابية لإدارة مكاتب المحاماة — بروتوكول الاستعلام والتحصيل الإلكتروني اللحظي

1. نظرة عامة على البنية المعمارية (Architecture Overview)

تعتمد منصة وزيرك (Waziruk) معمارية تحصيل إلكتروني مركزية مستقلة (Centralized EBPP Hub). تكون منصة وزيرك هي المرجع الأساسي المعتمد للفواتير، والمبالغ، وتواريخ الاستحقاق، وتفعيل الاشتراكات؛ بينما تعمل البنوك والمحافظ الإلكترونية كقنوات سداد مرتبطة عبر واجهة API موحدة ومؤمّنة.

  • Base URL (الإنتاج): https://waziruk.tech/api/v1/biller
  • معرّف المشترك المعتمد: رقم الهاتف المسجل لصاحب مكتب المحاماة (مثال: 771234567).
  • دعم العملات المتعددة (Multi-Currency): تعود كل فاتورة بـ 4 خيارات جاهزة للسداد: الدولار (USD)، الريال القعيطي الجنوبي (YER_SOUTH)، الريال القديم الشمالي (YER_NORTH)، والريال السعودي (SAR).

2. المصادقة والأمان (Authentication & Security)

يجب إرسال الترويسات الأمنية التالية مع جميع الطلبات الصادرة من خوادم البنك أو المحفظة:

4. تنفيذ التحصيل وتأكيد السداد (Payment Collection)

POST /api/v1/biller/pay   (أو Webhook: /api/v1/biller/notify)

نموذج الطلب (Request JSON):

{
  "invoice_no": "WZ-202611-0001",
  "amount_paid": 204980,
  "currency": "YER_SOUTH",
  "bank_reference": "KRM-8899123",
  "idempotency_key": "KRM-8899123"
}

نموذج الاستجابة (Response 200 OK):

{
  "status": "SUCCESS",
  "transaction_id": "WZK-20261127-A1B2C3D4",
  "invoice_no": "WZ-202611-0001",
  "bank_reference": "KRM-8899123",

5. الاستعلام عن حالة العملية والإلغاء (Status & Refund)

  • GET /api/v1/biller/status/{transaction_id_or_bank_reference} — للتحقق من مصير العملية في حال انقطاع الشبكة.
  • POST /api/v1/biller/refund — لعكس/استرداد عملية سداد وإعادة الفاتورة لحالة الانتظار وفق الصلاحيات.
