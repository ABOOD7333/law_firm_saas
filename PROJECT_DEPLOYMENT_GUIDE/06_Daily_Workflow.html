الدليل 06 • بطاقة العمل اليومية السريعة
دليل دورة العمل اليومية للمطور (Daily Workflow)
بطاقة الإجراءات السريعة (Cheat Sheet) لتطوير واختبار ورفع ونشر التحديثات بأمان

دورة العمل اليومية المعتمدة في 8 خطوات مرتبة

احتفظ بهذه الخطوات الثمانية كمرجع يومي معتمد في كل مرة تبدأ فيها بالعمل على منصة LawSaaS:

1
1. فتح المشروع وسحب آخر التحديثات من السحابة
قبل كتابة أي حرف، تأكد دائماً أن جهازك يملك أحدث كود عبر: git pull origin main
2
2. تنفيذ التعديل المطلوب في الكود
قم بتعديل ملفات الواجهة أو الراوترات أو القواعد وفق المهمة المطلوبة منك.
3
3. الاختبار المحلي على جهازك
شغل التطبيق محلياً وتأكد من فتح الصفحة في المتصفح وتجربة كافة الوظائف وعدم ظهور أخطاء.
4
4. فحص الملفات المتغيرة والتأكد من عدم وجود أسرار
اكتب git status للتأكد أنك لا ترفع ملفات .env أو بيانات غير مرغوبة.
5
5. حفظ التعديل محلياً (Commit)
اكتب git add . ثم git commit -m "رسالة توضح التعديل"
6
6. رفع التعديل إلى مستودع GitHub (Push)
ارفع تعديلاتك بثقة عبر الأمر: git push origin main
7
7. نشر التعديل على السيرفر الفعلي
ادخل للسيرفر عبر SSH، ونفذ: cd /opt/lawsaas && git pull origin main && docker compose up -d --build app
8
8. التحقق من السجلات واختبار الموقع الحي
افحص docker logs --tail 30 lawsaas_app ثم افتح https://waziruk.tech وتأكد من عمل الميزة الجديدة.

جدول الأوامر السريعة الأكثر استخداماً (Cheat Sheet)

الأمر مكان التنفيذ ماذا يفعل؟
git status جهازك المحلي معرفة الملفات المعدلة والتي تنتظر الرفع.
git diff جهازك المحلي عرض الأسطر التي تغيرت داخل الأكواد بدقة.
git add . جهازك المحلي تجهيز كافة الملفات المعدلة للحفظ.
git commit -m "..." جهازك المحلي حفظ التعديلات في سجل تاريخ المشروع.
git push origin main جهازك المحلي إرسال ورفع التعديلات إلى مستودع GitHub.
git pull origin main جهازك أو السيرفر جلب وسحب آخر التعديلات من GitHub.
docker ps السيرفر الفعلي عرض الحاويات الشغالة وحالتها الصحية ومنافذها.
docker restart lawsaas_app السيرفر الفعلي إعادة تشغيل التطبيق في ثانيتين.
docker logs -f lawsaas_app السيرفر الفعلي مراقبة سجلات وأخطاء التطبيق الحية لحظة بلحظة.
docker compose up -d --build app السيرفر الفعلي إعادة بناء وتشغيل التحديثات في الخلفية.
🏆 نصيحة هندسية للتميز

الفرق بين المطور العادي والمطور المحترف ليس حفظ الأوامر عن ظهر قلب، بل فهم دورة حياة البيانات والتأكد دائماً قبل الرفع من أمان الكود ونظافة بيئة العمل. باتباعك هذا الدليل، أصبحت تملك زمام مشروعك بالكامل وقادراً على تطويره ونشره بنفسك بثقة تامة!
