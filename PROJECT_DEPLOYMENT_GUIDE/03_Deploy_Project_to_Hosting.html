الدليل 03 • الاستضافة السحابية و VPS
دليل النشر والاستضافة السحابية لـ LawSaaS
تشغيل وإدارة المنصة على السيرفر الفعلي، ربط الدومين، وحاويات Docker

1. كيف يعمل مشروع LawSaaS على السيرفر الفعلي؟

تم نشر واستضافة منصة LawSaaS (وزيرك) على سيرفر سحابي خاص (VPS) بإعدادات إنتاج متطورة تضمن الاستقرار والأداء العالي:

المكون الإعداد الفعلي للمشروع الدور والمسؤولية
عنوان السيرفر (IP) 179.198.198.38 الخادم السحابي المستضيف لنظام Linux Ubuntu.
اسم النطاق (Domain) https://waziruk.tech الدومين الرسمي الموجه للسيرفر والمحمي بشهادة أمان SSL (Let's Encrypt).
مسار المشروع /opt/lawsaas/ المجلد الفعلي الذي يحتوي على أكواد وملفات المشروع على السيرفر.
حاوية التطبيق lawsaas_app (Docker) الحاوية التي تشغل خادم FastAPI بواسطة Uvicorn على المنفذ الداخلي 8000.
الخادم الوكيل (Proxy) Nginx يستقبل الزوار على المنفذ 443 و 80 ويمرر الطلبات بأمان إلى الحاوية.

2. الدخول إلى السيرفر عبر SSH

للتحكم في السيرفر وإدارته من جهازك، افتح نافذة PowerShell واكتب أمر الاتصال الآمن (SSH):

الاتصال بالسيرفر
PS > ssh root@179.198.198.38 # أدخل كلمة المرور الخاصة بالسيرفر عند طلبها root@lawsaas-vps:~# # أنت الآن داخل السيرفر بنجاح!

3. خطوات نشر تحديث جديد على السيرفر (Production Deployment)

عندما ترفع كوداً جديداً إلى GitHub وتريد تحديث الموقع الحي على السيرفر، اتبع الخطوات الأربع التالية:

1
الدخول إلى مجلد المشروع على السيرفر
انتقل للمجلد الرسمي للتطبيق: cd /opt/lawsaas
2
سحب آخر التعديلات من GitHub
اكتب git pull origin main لجلب التعديلات الجديدة التي رفعتها.
3
إعادة بناء وتشغيل الحاوية السحابية
اكتب docker compose -f docker-compose.yml up -d --build app لتطبيق التحديث وتحديث الحاوية في الخلفية.
4
مراقبة السجلات والتأكد من انطلاق الخادم
اكتب docker logs -f --tail 50 lawsaas_app للتأكد من رسالة Application startup complete.
الأوامر مجمعة للنشر السريع
root@lawsaas-vps:~# cd /opt/lawsaas root@lawsaas-vps:/opt/lawsaas# git pull origin main root@lawsaas-vps:/opt/lawsaas# docker compose up -d --build app root@lawsaas-vps:/opt/lawsaas# docker logs --tail 30 lawsaas_app

4. إدارة متغيرات البيئة (.env) على السيرفر

ملف .env على السيرفر يحتوي على البيانات الحقيقية السرية لقاعدة البيانات ومفاتيح الـ API. لتعديل أي إعداد (مثل إضافة مفتاح جديد لـ Gemini أو إعدادات بريد SMTP):

root@lawsaas-vps:/opt/lawsaas# nano .env # عدل القيمة المطلوبة في المحرر، ثم اضغط Ctrl + O للحفظ، ثم Enter، ثم Ctrl + X للخروج. # بعد تعديل .env، يجب دائماً إعادة تشغيل الحاوية لتقرأ القيم الجديدة: root@lawsaas-vps:/opt/lawsaas# docker restart lawsaas_app

5. كيف تتأكد أن الموقع يعمل بنجاح بعد التحديث؟

  1. الفحص السريع من الطرفية (Terminal):
    اكتب curl -I https://waziruk.tech وتأكد من استلام كود الحالة HTTP/2 200 أو HTTP/2 303.
  2. الفحص البصري من المتصفح:
    افتح المتصفح في وضع التصفح الخفي (Incognito) وادخل إلى https://waziruk.tech، وتأكد من تسجيل الدخول وتجربة الميزة الجديدة التي قمت بنشرها.
  3. فحص سجلات الأخطاء في Nginx:
    اكتب tail -f /var/log/nginx/error.log للتأكد من عدم وجود أخطاء في تمرير الاتصال.
