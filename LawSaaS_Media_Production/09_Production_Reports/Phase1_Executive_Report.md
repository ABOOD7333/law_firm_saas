## 3. خطة إنتاج الإعلان التجاري الرئيسي (المرحلة الأولى)
- **المدة المقررة**: 60 إلى 75 ثانية.
- **الصوتيات**:
  - تعليق صوتي باللغة العربية الفصحى بصوت رخيم وقور وجذاب (`ar-SA-HamedNeural` عبر محرك النطق السحابي المطور).
  - موسيقى تصويرية تقنية ملهمة ورسمية مولدة بالكامل (100% بدون أي حقوق ملكية فكرية) مع تخفيض ذكي للصوت أثناء تحدث المعلق (Ducking).
  - مؤثرات صوتية احترافية خفيفة (Whoosh / UI Chimes / Camera Shutter).
- **العناصر البصرية**:
  - تصوير حقيقي لواجهات النظام (Landing, Dashboard, Cases, Calendar, Trust Accounts) باستخدام بيانات تجريبية وهمية احترافية تضمن سرية الموكلين التامة.
  - نصوص متحركة حركية (Kinetic Typography) بالخط الكوفي/النسخي الحديث (Cairo) متزامنة بنسبة 100% مع النطق.
  - إبراز شعار الميزان الذهبي الفاخر لمنصة LawSaaS في الافتتاحية والختام.
  - دعوة صريحة للزيارة والتسجيل: `waziruk.tech`.
- **المقاسات المعتمدة**:
  1. **النسخة الأفقية 16:9** (1920×1080 Full HD) مخصصة لموقع الويب و YouTube.
  2. **النسخة الرأسية 9:16** (1080×1920 Full HD) مخصصة لمنصات TikTok و Instagram Reels.
  3. **نسخة الإنستغرام المربعة 1:1 أو 4:5** (1080×1080 / 1080×1350) للتغذية الإخبارية (Feed).
